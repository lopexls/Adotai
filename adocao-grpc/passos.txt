instalar grpc
pip install grpcio grpcio-tools


após alterações no .proto, remover arquivos
adocao_pb2.py
adocao_pb2_grpc.py

e executar no cmd (dentro da pasta adocao-grpc)
python -m grpc_tools.protoc -I proto --python_out=. --grpc_python_out=. proto/adocao.proto


para rodar servidor:
python -m animais.servidor

para rodar cliente:
python -m adocao.cliente
